    Theory

    What is Finite Automata?

    A finite automaton is a mathematical model consisting of a finite number of states and transitions. It processes an input string, one symbol at a time, and determines whether the string satisfies a defined pattern — accepting or rejecting it based on the state it ends in.

    In this project, URLs are treated as input strings. The finite automaton scans URL patterns and changes states when suspicious patterns are encountered, moving progressively from a start state toward a final classification state.

    START → URL PROCESSING → PATTERN CHECK → SUSPICIOUS / SAFE → FINAL STATE
